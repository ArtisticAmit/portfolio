# Live MCQ — Product Redesign — image drop-in slots

Drop PNG files into this folder using the exact filenames below. The case study
page (`src/pages/ProjectDetail.jsx`, `'live-mcq-redesign'` entry) references these
paths directly by URL — no code changes needed once a file lands here.

- `clarity-evidence.png` — Microsoft Clarity heatmap or rage-tap recording of the old home/login
- `research-synthesis.png` — affinity map / segment boards from interviews & task sessions
- `ia-before-after.png` — signature visual: sprawl of ~24 ungrouped feature tags vs. the nested Target → Subject → Exam/Study taxonomy
- `adaptive-nav.png` — triptych: compact (bottom bar), medium (navigation rail), expanded (navigation drawer)
- `new-home.png` — the redesigned goal-aware home (phone + desktop if available)
- `onboarding-before-after.png` — old login beside the new first-run flow

Until a file exists, the browser shows the image's alt text in its place instead
of a broken build.

Also flagged in the page data, not images: `TODO(role)` and `TODO(timeline)` in
the hero meta, and `TODO(content): test-findings` — qualitative usability
results for the Test stage, not yet supplied.

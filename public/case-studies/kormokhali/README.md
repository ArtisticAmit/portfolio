# kormokhali — image drop-in slots

The kormokhali story (`src/pages/ProjectDetail.jsx`, `'kormokhali'` entry)
shows a "Visual coming soon" banner for each image below until a PNG with the
exact filename is dropped here. No code change needed.

- `cover.png` — the feed and a recruitment timeline on a phone
- `recruitment-timeline.png` — a recruitment page with its steps, circular to result
- `share-picture.png` — a share picture as posted to Facebook and Instagram
- `feed-card.png` — the one-column feed with the rewritten card date line
